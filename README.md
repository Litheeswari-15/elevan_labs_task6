# Task 6: Sales Trend Analysis Using Aggregations

## Objective
The objective of this task is to analyze sales trends using SQL aggregation functions. The analysis focuses on understanding revenue, profit, order distribution, and sales performance across different regions, categories, and cities.

## Tools Used
- SQLite
- DB Browser for SQLite

## Dataset
SampleSuperstore Dataset

### Attributes Used
- Ship Mode
- Segment
- Country
- City
- State
- Postal Code
- Region
- Category
- Sub-Category
- Sales
- Quantity
- Discount
- Profit

## SQL Concepts Applied
- SELECT
- GROUP BY
- ORDER BY
- SUM()
- COUNT()
- LIMIT
- Aggregate Functions

## Analysis Performed

### 1. Sales by Category
Calculated total sales for each product category and identified the highest-selling categories.

### 2. Profit by Category
Analyzed total profit generated by each category to determine profitability.

### 3. Sales by Region
Compared sales performance across different geographical regions.

### 4. Quantity Sold by Category
Measured the total quantity of products sold in each category.

### 5. Top Cities by Sales
Identified the top-performing cities based on total sales revenue.

### 6. Regional Performance Summary
Generated a summary showing:
- Total Orders
- Total Sales
- Total Profit

for each region.

## Key Findings
- Sales performance varies across regions and categories.
- Certain categories contribute significantly more revenue than others.
- Profitability is not always proportional to sales due to discounts and operational factors.
- Top-performing cities account for a substantial portion of total revenue.

Successfully used SQL aggregation techniques to analyze sales data and derive meaningful business insights. This task improved understanding of:
